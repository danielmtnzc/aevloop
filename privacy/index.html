Política de Privacidad

Última actualización: 14 de marzo de 2026

En Vibes Code Studios, accesible desde vibescodestudios.com, una de nuestras principales prioridades es la privacidad de nuestros visitantes y usuarios. Este documento contiene los tipos de información que recopilamos y cómo los utilizamos.

1. Información que recopilamos

Nuestras aplicaciones están diseñadas para funcionar con el mínimo de datos personales posible. Sin embargo, podemos recopilar:

  • Información del dispositivo: Modelo de hardware, versión del sistema operativo e identificadores únicos del dispositivo (IDFA/AAID).
  • Datos de uso: Estadísticas anónimas sobre cómo interactúas con la app.
  • Información de diagnóstico: Registros de errores (Crash logs) para solucionar fallos técnicos.

2. Uso de servicios de terceros

Podemos emplear a terceras empresas para facilitar nuestras aplicaciones. Estos terceros tienen acceso a su información técnica solo para realizar tareas en nuestro nombre:

  • Google AdMob: Utilizado para mostrar anuncios.
  • Firebase Analytics: Para entender el comportamiento del usuario de forma agregada.

3. Consentimiento y Menores

Vibes Code Studios no recopila conscientemente información personal de menores de 13 años. Si cree que un menor proporcionó datos, contáctenos de inmediato.

4. Sus Derechos (GDPR / CCPA)

Usted tiene derecho a solicitar acceso, rectificación o eliminación de cualquier dato técnico recopilado enviando un correo a development@vibescodestudios.com.
